## ✅ M-GOOGLE-CHAT-PLACEHOLDER-IS-A-SPEECH-BALLOON-1 — the waiting line is 💬 and still becomes «…»

**Why:** the operator, 2026-09-30, found «Sto scrivendo…» poor and chose a symbol over dots that move while the
assistant works. Each move would be an edit, and Google allows one write per second in a conversation, so moving
dots would spend that quota on the long turns, where the answer's own posts need it. A symbol needs no translation.

**Tasks:**
- [x] The placeholder is 💬 (U+1F4AC), the same in every language; the localised line and its plumbing are removed
- [x] It still becomes «…» at every end path (answer, empty reply, failure, time limit, throw), once, by its own turn
- [x] Test: unit — the post is exactly 💬 for a message in each of the four languages, and the edit tests still pass

**Done when:** on Google Chat a 💬 appears on receipt and stands as «…» above the answer.

## Out of scope for v0.1 (deferred)

- **Slack / Telegram adapters** — Tier-0 only, by customer request.
- **Multi-bot per agent** — one bot per template is the PoC contract.
- **Persistent session-store across container redeploys** — v0.1
  relies on mem0 + the persisted workspace inside the agent container
  to recover continuity on the next user turn. A dedicated
  session-store (à la OpenACP) is a v0.2 concern.
- **Skill command pinning, slash commands, button-based permission
  approval** — explicit UX-incompatibility per cerase M2 rules.
- **Doctor checks** — deferred; structured pino logs cover the PoC
  observability need.
