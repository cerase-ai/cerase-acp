## 📋 M-A-TURN-S-LANGUAGE-FOLLOWS-THE-CONVERSATION-1 — the step line and a turn's language hint follow the conversation, not two articles of one message

Placed by the operator on 28 October, with cerase-core's v0.3.5.

**Why:** a scheduled message holding «le» twice was read as French: `src/turn-meta.ts:207` lists «le» only for French, as it does «ce», «ne» and «qui» at 209, 216 and 217. `noticeLang` (`src/dispatcher.ts:554`) reads the current message before the conversation's language, so Matilde's step line said «Je lis dans Odoo». On `guidance` 8 of 224 turns in three days had a step line in another language than the conversation's, and after a bridge restart one message alone set `lang=fr` for the model twice.

**Approach:** words Italian and French share count for neither language; `noticeLang` reads the conversation's language first and the message only when the conversation has none; after a restart one message does not set the language alone.

**Tasks:**
- [ ] Test: a message holding «le» twice keeps an Italian conversation Italian, in the step line and the hint; red first
- [ ] Test: after a restart, one message alone does not set the conversation's language
- [ ] Shared Italian and French words count for neither, and `noticeLang` reads the conversation first
- [ ] Commit & push
- [ ] The next cerase-core release pins this bridge
- [ ] Live on the test machine: a scheduled Italian message with two articles gets an Italian step line

**Done when:** an Italian conversation's step lines and language hints stay Italian whatever articles one message carries.
